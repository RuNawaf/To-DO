# لوحة التزاماتي — TaskWidget

تطبيق سطح مكتب (Electron + React + TypeScript) — ليس موقع ويب. لوحة مهام وعدّادات تنازلية تبقى **أمامك دائمًا** فوق باقي النوافذ، بدل أن تحتاج تفتحها كل مرة.

## الفكرة

- Widget عائم صغير، قابل للتثبيت في أي مكان على الشاشة، وقابل لتغيير الحجم.
- وضعان: **Compact** (اسم المهمة + الوقت المتبقي فقط) و **Expanded** (تفاصيل أكثر).
- **Always on Top** اختياري، شفافية تقل عند عدم الاستخدام وترجع كاملة عند تمرير الماوس.
- يبدأ تلقائيًا مع تشغيل الجهاز (Windows/macOS)، ويحفظ مكانه وحجمه بعد إعادة التشغيل.
- أيقونة في شريط النظام (Tray) للتحكم السريع دون إغلاق التطبيق فعليًا.
- **كل تصنيف له شكل مختلف تمامًا** بدل نموذج واحد عام لكل المهام:
  - **دراسة / اختبار** → أجزاء دراسة (Chapters...) + نسبة إنجاز، وموعد مساعد اختياري لا يُلزمك.
  - **ورشة / محاضرة** → تاريخ ووقت + مكان/رابط + "☐ حضرت".
  - **نادي** → يوم ووقت أسبوعي متكرر + "☐ تم اليوم" (يتجدد تلقائيًا كل أسبوع).
  - **فرصة / تقديم** → الموعد النهائي إلزامي + Checklist (قراءة الشروط، تجهيز السيرة...) + "ليش أبي أقدم؟".
  - **مشروع** → مراحل (تخطيط، تنفيذ، مراجعة، تسليم...) + موعد نهائي اختياري أو إلزامي حسب اختيارك.
  - **شخصي** → عنوان + موعد اختياري + ملاحظات، بسيط بدون تعقيد.
- كل مهمة تحمل أيضًا: الأولوية، وملاحظة **"ليش لازم أسويها؟"** تظهر تحتها كتذكير بالسبب.
- عمود **"أفكار"** بجانب "الالتزامات" مباشرة (بدون تبويبات) — لأشياء خفيفة تبيها تدوّنها بسرعة: عنوان، وقت اختياري، ووصف اختياري، وزر ✓ لإنهائها. يظهران جنبًا إلى جنب في نفس الشاشة، وينزلان فوق بعض تلقائيًا إذا ضاقت مساحة النافذة.
- عدّاد تنازلي حي ("باقي يومين"، "باقي 4 ساعات"...) والمهام الأقرب موعدًا ترتفع تلقائيًا لأعلى القائمة.
- زر **"مالي خلق"** يعرض رسالتك لنفسك + أصغر خطوة تبدأ فيها + مؤقّت 10 دقائق للانطلاق.
- إشعارات نظام (Notifications) قبل الموعد بمدد تصاعدية (3 أيام / يوم / 4 ساعات / ساعة / 30 دقيقة) تتضمن سبب أهمية المهمة، وليس نص عام.
- دعم كامل للعربية و RTL، ووضع فاتح/داكن يتبع النظام أو يُضبط يدويًا.
- تفاعل سريع من البطاقة مباشرة: ✓ إنهاء، → فتح التفاصيل، ⏰ تأجيل التذكير، 📝 ملاحظة سريعة.

## التشغيل أثناء التطوير

```bash
npm install

# طرفية 1: خادم الواجهة (renderer) مع Hot Reload
npm run dev

# طرفية 2: تشغيل Electron موجّهًا لخادم التطوير
npm run electron:dev
```

## بناء نسخة تجريبية وتشغيلها

```bash
npm run build   # يبني الواجهة (dist) وعملية Electron (dist-electron)
npm start       # يبني ثم يشغّل التطبيق من الملفات المبنية
```

## تحزيم التطبيق كملف تثبيت (Windows / macOS / Linux)

```bash
npm run dist
```

يستخدم `electron-builder` وفق الإعدادات في `package.json` (`build`). المخرجات في مجلد `release/`.

## هيكلة المشروع

```
electron/         عملية Electron الرئيسية (نافذة، Tray، إشعارات، تخزين محلي)
  main.ts          إنشاء النافذة (بلا حواف، شفافة، Always on Top)، Tray، IPC
  preload.ts       جسر الأمان بين الواجهة وعملية Electron (contextBridge)
  store.ts         تخزين محلي دائم عبر electron-store
  notificationScheduler.ts  فحص المواعيد كل 30 ثانية وإطلاق إشعارات النظام
shared/            أنواع بيانات وقنوات IPC مشتركة بين الواجهة وElectron
  types.ts         شكل المهمة لكل تصنيف (Task كـ discriminated union)
  taskLogic.ts      الموعد الفعّال لكل نوع مهمة، حساب التكرار الأسبوعي، نسبة الإنجاز
  migrate.ts        ترقية بيانات محفوظة بالشكل القديم (قبل تخصيص كل تصنيف)
src/               واجهة React
  components/      TitleBar, TaskCard, TaskFormModal (نموذج مختلف حسب التصنيف),
                    TaskDetailModal, MotivationModal ("مالي خلق"), SettingsPanel,
                    ChecklistEditor, ProgressBar
  store/           حالة المهام والإعدادات (zustand) + مزامنة مع electron-store
  utils/           تنسيق العدّاد التنازلي وألوان التصنيفات/الأولوية
  styles/          تصميم Minimal يدعم RTL والوضعين الفاتح/الداكن
```

## ملاحظات

- التشغيل التلقائي عند بدء الجهاز (`autoStart`) مدعوم بشكل كامل على Windows وmacOS عبر واجهة Electron الرسمية. على Linux قد تحتاج لإضافة ملف `.desktop` يدويًا حسب بيئة سطح المكتب المستخدمة.
- جميع البيانات تُخزَّن محليًا على جهازك فقط (لا يوجد اتصال بأي خادم خارجي).
